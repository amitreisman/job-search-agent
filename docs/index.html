Design decisions

  
The interesting part of an agent is rarely the model call. It is what the system is allowed to do, and what happens when it is wrong.

  

    
Control
Human in the loop by design
The agent drafts; I decide. Buttons generate a CV or letter on demand, and applying, messaging recruiters and sending anything stay manual. Autonomy is a product decision, not a default.

    
Trust
Grounded generation, not free writing
The CV is built from a verified facts file with a "do not claim" list. Names, titles, dates and education are fixed in code, so the model only writes bullets. A real catch: it once turned "probably Dynamics 365" into a stated fact, so the rule now forbids stating inferences.

    
Explainability
A score you can argue with
Five weighted components with strengths and gaps that must cite the CV. Director-level roles are a hard filter, so other components cannot rescue them.

    
Reliability
Failures never hide a job
A broken job board does not stop the run, and its jobs stay in the report. If a score fails, the job shows as "not assessed" instead of vanishing. Reports always list every open match, so the output is a state, not a diff.

    
Cost
Rules first, model second
Title, location and age filters run for free. The model scores only survivors, once per job. No new jobs means no report and no model calls.

    
Deliberately not built
LinkedIn scraping and auto-messaging
Scraping breaks the platform's terms and risks the account; automated outreach damages the relationship it is meant to start. The agent uses companies' public job APIs instead.

  






  
Limits and what is next

  

    
Scores are not calibrated yet
They come from model judgement against a written rubric. Next: compare them with human judgement on a labelled set and report agreement.

    
Coverage is partial
It covers companies whose job boards expose a public API. Sites that render everything in the browser are not covered yet.

    
Some posting dates are approximate
A few boards only expose a last-updated time, so a refreshed old job can look newer than it is.
